GTA DUSHANBE 3D — ЧИХЕЛ БАРНОМА КАРДАН

ВАРИАНТИ 1 — PWA (содатарин, барои компютер ва телефон)
1. Ҳамаи файлҳои ин ҷузвдонро (index.html, sw.js, manifest.webmanifest, icon-*.png) ба GitHub репозиторӣ боргирӣ кунед.
2. Settings > Pages > Branch: main > Save. Баъди 1-2 дақиқа линк пайдо мешавад: https://НОМ.github.io/РЕПОЗИТОРИ/
3. Линкро дар Edge ё Chrome кушоед. Дар тарафи рости сатри адрес тугмаи "Насб кардан" (Install app) пайдо мешавад.
4. Баъди насб бозӣ ҳамчун барнома бо нишона дар Start/Desktop кушода мешавад ва пас аз як маротиба кушодан бе интернет ҳам кор мекунад.
   Мултиплейер ва линки ?room=РАМЗ ҳам аз ҳамин суроға кор мекунад.

ВАРИАНТИ 2 — .EXE БАРОИ WINDOWS (Electron)
1. Node.js-ро аз nodejs.org насб кунед.
2. Ҷузвдони "electron"-ро кушоед, дар сатри адрес cmd нависед ва Enter занед:
      npm install
      npm start          (санҷиш)
      npm run build      (файли .exe дар ҷузвдони dist пайдо мешавад)
3. Ин .exe-ро ба дӯстон диҳед. Қайд: китобхонаи three.js аз интернет бор мешавад. Барои кори комилан офлайн:
   - https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
   - https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/controls/PointerLockControls.js
   ин ду файлро боргирӣ карда, дар index.html (дар ҷузвдони electron) дар теги <script src="..."> бо номи файлҳои маҳаллӣ иваз кунед.

ВАРИАНТИ 3 — ANDROID (APK)
Линки GitHub Pages-ро дар сайти pwabuilder.com ворид кунед ва "Package for Stores > Android" -ро интихоб кунед. APK-ро мегиред.
Қайд: идоракунӣ (WASD, муш) барои телефон мувофиқ нест — тугмаҳои сенсорӣ лозиманд.


ВИДЕО-ПЕШНАМОИШ (ҳамчун дар бозиҳои GTA)
Видеои худро бо ин номи дақиқ дар ҷузвдони "video" гузоред:
   video/intro.mp4        (беҳтараш H.264 + AAC; "intro.webm" ва "intro.mov" низ қабул мешавад)
Бозӣ ҳангоми кушодан аввал видеоро нишон медиҳад. Enter — гузаштан (ҳама метавонанд гузаронанд).
Агар файл набошад, ба ҷои он матни кинематикии сюжет нишон дода мешавад (ва ҳам бо Enter гузаронида мешавад).
Баъд "клик кунед" -и муқаррарӣ меояд ва сюжет оғоз мешавад.
Эзоҳ: видео бояд дар ҳамон ҷузвдон бо index.html бошад. Дар Chrome/Edge аз файли маҳаллӣ (file://) ҳам кор мекунад.

КЛАВИШҲОИ НАВ: J — меню (миссияҳо, таксӣ, паёмрасонӣ, пешнамоиши аз нав, сюжетро аз нав оғоз кардан).
Enter — муколамаро идома додан. 1/2/3 — интихоби ҷавоб.


КЛАВИШҲОИ НАВ (нусхаи 3)
J — миссияҳо: 3 сюжет (Тоҷи Исмоили Сомонӣ / Тоҷҳои Заррин / Ронандагони Шаб), таксӣ, паёмрасонӣ, доставка, пойга бо вақт, пойгаи Душанбе → Хуҷанд бо ҷадвали ғолибон
K — гараж ва мағоза: нақлиёт (Camry/Микроавтобус/Боркаш), ранг, тюнинг (муҳаррик, сарфи кам, нитро), либос, бомба/мина/ёрии аввал, борон, радио
B — иваз кардани радио, Y — эвакуатор (вақте сӯзишворӣ тамом шуд)
Мусиқии худатон: файлҳоро music/1.mp3, music/2.mp3 ... (то 5) гузоред — "Мусиқии шумо" дар радио пайдо мешавад.


СЮЖЕТҲО (J — меню): Тоҷи Исмоили Сомонӣ · Тоҷҳои Заррин · Ронандагони Шаб · Сигнали Шабона · Дузди Соат (нав).

ЭКРАНИ АСОСӢ: СТАРТ · МУЛТИПЛЕЕР · НАСТРОЙКА
- Пас аз видео-пешнамоиш экрани асосӣ меояд. Esc ҳангоми бозӣ онро боз мекушояд (ДАВОМ).
- МУЛТИПЛЕЕР → "ВОРИДИ ЗУД": бе сохтани ҳуҷра ба бозии умумӣ ворид мешавед (то 10 нафар). Агар касе набошад, шумо хост мешавед.
  Ҳуҷраи шахсӣ бо рамз низ боқӣ мондааст.
- НАСТРОЙКА: ҳассосияти муш, FOV, овоз, сифати тасвир, соя. Ҳама захира мешавад.
- Қайд: мултиплейр аз PeerJS (интернет) кор мекунад; хост бояд саҳифаро боз нигоҳ дорад.

УСЛУБИ ТАСВИР «WOBBLY LIFE»
- Рангҳои равшану сер, сояи нарм, офтоби нарм ва осмони равшан; одамон ҳангоми роҳ рафтан лаппиш мезананд.
- Дар Настройка: тугмаи «🎨 Услуби мултфилмӣ» ва ҷойи тағйири ранг ва нармии рӯшноӣ.
- Агар дар дастгоҳи шумо шейдер кор накунад, услуб худ хомӯш мешавад.

МОШИНҲОИ УСЛУБИ «NEED FOR SPEED»
- Мошини бозингар, ҳамаи мошинҳои трафик, таксӣ, милиса, рақибони пойга ва мошинҳои бозингарони онлайн модели нав доранд:
  корпуси паст, спойлер, диски хромӣ, супортҳои сурх, дудкашҳо, рахҳои пойга ва неон дар таги мошин.
- Ҳангоми суръати баланд майдони диди васеъ мешавад ва хатҳои суръат пайдо мешаванд.
- Микроавтобус, боркаш ва автобусҳо ҳоло бетағйир мондаанд.

МОШИНҲО, БОРКАШҲО, ГАРАЖҲО ВА ОДАМОН
- 19 намуди нақлиёт: Mercedes S-Class, BMW M5, Maserati, Tesla Model S, Tesla Cybertruck, Porsche 911, Lamborghini, Bugatti,
  Ford Mustang, Land Cruiser, Mercedes G-Class, Range Rover, Chery Tiggo, Hilux, лимузин, Camry, микроавтобус ва ду боркаш.
- Боркашҳои Webmarket (норинҷӣ) ва Laklak (сабз) бо ёзуҳо дар паҳлӯ ва қафо. Онҳо дар кӯчаҳои шаҳр низ мераванд.
- Гаражҳо (нишони норанҷӣ) дар Душанбе, Дубай, Чин, Боку ва шаҳрчаи вилоятҳо. K танҳо дар назди гараж кор мекунад.
- Дар чор шаҳри дигар низ одамон дар кӯчаҳо роҳ мераванд (бо тир онҳо мемиранд ва худ аз худ пайдо мешаванд).
- Хатои тир: тир ба одамон намерасид, ислоҳ шуд (3 тир мекушад).

ОФИС ВА СУРАТИ ШУМО
- Дар Душанбе бинои "ОФИС" ҳаст (нишони кабуд дар харита). Ба назди дарвоза равед ва F занед.
- Дар дохил: баннери калон дар девори қафо бо сурат ва номи шумо, шахс дар курсии корӣ, миз бо монитор, курсиҳо, диван, шкаф, гул, байрақ.
- Сурат гузоштан (3 роҳ):
  1) Дар офис клавиши U -ро занед ва сурат интихоб кунед (дар браузер захира мешавад).
  2) make-photo.html -ро кушоед, суратро интихоб кунед, photo.js-ро боргирӣ кунед ва ба ҷои photo.js дар ҷузвдони бозӣ гузоред
     (ин роҳ барои ҳама дӯстон ҳам кор мекунад, агар бозиро бо photo.js паҳн кунед).
  3) Дар сервер/GitHub Pages: суратро ба номи photo/me.jpg гузоред.
  Қайд: аз file:// браузер суратро аз файли оддӣ нахондан мегирад, бинобар ин роҳи 1 ё 2 лозим аст.
- Ном ва шиорро дар photo.js тағйир диҳед.
SAIFIYAT
- Настройка -> Сифати тасвир: Паст/Миёна/Баланд ва "Худкор" (агар FPS паст бошад, сифат худ паст мешавад).

НАМОИШИ 3D ДАР ГАРАЖ (K)
- Дар боло мошин мегардад (бо муш кашида гардонидан мумкин аст).
- Курсорро рӯи номи мошин гузоред — худи он мошин нишон дода мешавад (бо суръат, сарф ва нарх).
- Курсорро рӯи ранг гузоред — мошин бо ҳамон ранг намоён мешавад, пеш аз харидан.

ИСЛОҲ: пас аз пӯшидани меню (K, J) курсор худкор ба бозӣ бармегардад. Агар браузер иҷозат надиҳад, тугмаи «▶ ДАВОМ» пайдо мешавад.

ҶАҲОН: РОҲҲО, ТРАФИК, ХАРИТА (услуби GTA San Andreas)
- Роҳҳои нав: пайвасткунакҳо аз Душанбе, кроссҳои Чин ва шаҳрчаи вилоятҳо, ва ҳалқаи шоҳроҳӣ байни Дубай-Боку-Чин-шаҳрча. Ҳама ҷо бо ҳам пайвастанд.
- Дар ҳамаи шаҳрҳо ва шоҳроҳҳо мошинҳои услуби NFS мераванд; дар байни онҳо Tesla-и сафед (тезтар ва ҳамвор).
- Дар Дубай, Чин, Боку ва шаҳрчаи вилоятҳо одамон зиёд шуданд (28 нафар дар ҳар шаҳр).
- Харитаи калон (N): тамоми ҷаҳон бо баҳр, заминҳо, роҳҳо, нуқтаҳои гараж/офис/миссия, ном ва тири шумо. Чархак ё + − барои масштаб, 0 аз нав.
- Радар: давр, ба самти ҳаракат мегардад, бо нишони шимол (N).

ШАҲРИ КАЛОНТАР (нав)
- Душанбе то ±750 васеъ шуд (ҳалқаи берунӣ бо роҳҳои нав). Кӯҳҳо ба масофаи 3400+ бурда шуданд; туман сабуктар шуд.
- Корнерҳо: ЗООПАРК (шер, фил, зурнафа, зебра, пингвин, фламинго, қафаси парранда), БОҒИ БОТАНИКӣ (оранжерея, гулзорҳо, гунбазҳо, дарахтони нодир),
  ШАРШАРА (шаршараи ҷараёнӣ, ҳавз, кӯл, кӯпрук, рангинкамон), БАНДАР (аз роҳ ба ин ҷо кӯчонида шуд).
- 4 боғи карусел: карусел бо аспҳо, чархифалак, роликкостер (дар 2 ҷо), киоскҳо.
- Хонаҳои нав (3 деҳа), бурҷҳои истиқоматӣ, стадион, беморхона, Тоҷикистон Молл, донишгоҳ, расадхона, сарои ях, аквариум, меҳмонхона, майдони фаввора.
- Санҷиши ҷойгиршавӣ: фурудгоҳ, бандар ва маҷмааи масҷид аз болои роҳ гузашта буданд — кӯчонида шуданд; 2 объект дар x=-750 низ.
